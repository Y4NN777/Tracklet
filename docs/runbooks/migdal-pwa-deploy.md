# Runbook: PWA Build & Deploy (Migdal)

**Team:** Migdal (Infrastructure)

## Steps

1. `npm run build` — production build with Next.js static export.
2. Verify `out/` directory contains: `index.html`, `_next/static/`, service worker.
3. Verify `manifest.json` has correct app name, icons, and start URL.
4. Test on Android Chrome: load from local server, verify "Add to Home Screen".
5. Package for distribution (APK via PWA wrapper or Play Store upload).

## Assets

- Favicon / icons: `public/` directory
- Manifest: `public/manifest.json`
- Service worker: auto-generated by Next.js PWA plugin
