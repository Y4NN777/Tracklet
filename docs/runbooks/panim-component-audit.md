# Runbook: Component Audit (Panim)

**Team:** Panim (Frontend / UI)

## When to Run

Before any UI release. After any component is added or modified.

## Steps

1. Open every screen on the reference device (390px Android).
2. Check all components against DESIGN.md tokens (color, typography, spacing).
3. Verify every action is reachable in ≤ 2 taps.
4. Test with no data (first launch).
5. Test with large data (1000+ transactions).
6. Verify dark mode is not required (light mode only).
7. Check all French labels are simple and direct — no "comptabilité".
